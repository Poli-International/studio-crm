# Decodificador de Certificación de Materiales: Manual de Usuario (Español)

Poli International Estándares Profesionales para Joyería Corporal

## Resumen
El Decodificador de Certificación de Materiales es una herramienta clínica de referencia para anilladores profesionales, auditores de calidad y clientes informados. Analiza normas metalúrgicas (ASTM, ISO), evaluaciones de polímeros médicos (USP Clase VI) y directivas de seguridad química (EU REACH Entrada 27).

Los materiales biocompatibles de grado implante avalados por normas internacionales incluyen:
- **ASTM F136 / ISO 5832-3 Titanio (Ti-6Al-4V ELI)**
- **BioFlex® Copolímero Médico PP-R (USP Clase VI / ISO 10993)**
- **ASTM F138 / ISO 5832-1 Acero Inoxidable de Implante (316LVM)**
- **ASTM F2229 Niobio (Sin alear)**
- **Vidrio Borosilicato 3.3 (ISO 3585)**
- **Oro Macizo 14K/18K Biocompatible (Sin níquel)**

## Módulos del Sistema

### 1. Lector de Certificados y Textos Predefinidos
Inspecciona etiquetas comerciales, pedidos o certificados de colada. Seleccione entre 6 preajustes para evaluar declaraciones de proveedores válidas o engañosas. Evalúa límites químicos, niveles de biocompatibilidad y señales de advertencia.

### 2. Generador de Cuestionario para Proveedores
Elija el material objetivo y la aplicación clínica (perforación inicial, cicatrizada, piel sensible/alergia, cavidad oral o anclaje dérmico). Produce las preguntas técnicas exactas para su fabricante, los requisitos de respuesta aceptable y las alertas rojas de descalificación. Listo para imprimir.

### 3. Matriz Declaración-Evidencia
Relaciona 12 afirmaciones comerciales habituales (ej. «Grado Implante», «Acero Quirúrgico», «Hipoalergénico», «BioFlex», «Libre de Níquel») con la documentación reglamentaria y clínica exigible.

### 4. Comparador de Materiales Certificados
Compare hasta 3 materiales en paralelo según análisis de composición, resistencia mecánica, potencial de corrosión galvánica y esterilización bajo criterios uniformes.

### 5. Registro de Conformidad del Estudio
Guarde las inspecciones de recepción de pedidos directamente en la memoria local y privada de su navegador. Genere actas fechadas para expedientes de inspección sin servidores externos ni rastreo.

## Accesibilidad y Adaptación Móvil
- Estructura 100% estática y operable sin conexión a Internet.
- Totalmente adaptable a teléfonos móviles (desde 360 px), tabletas y ordenadores.
- Botones y controles táctiles de al menos 44 px para uso con guantes sanitarios.
- Contraste visual certificado (mínimo 4,5:1 según WCAG AA) en modos claro y oscuro.
