# Décodeur de Certification des Matériaux : Guide d'Utilisation (Français)

Poli International Normes Professionnelles pour Bijoux de Corps

## Vue d'Ensemble
Le Décodeur de Certification des Matériaux est un outil de référence clinique conçu pour les perceurs professionnels, les auditeurs qualité et les consommateurs avertis. Il clarifie les normes métallurgiques (ASTM, ISO), les évaluations des polymères médicaux (USP Classe VI) et les directives réglementaires (EU REACH Entrée 27).

Les matériaux biocompatibles de qualité implantable reconnus par les normes internationales comprennent :
- **ASTM F136 / ISO 5832-3 Titane (Ti-6Al-4V ELI)**
- **BioFlex® Copolymère Médical PP-R (USP Classe VI / ISO 10993)**
- **ASTM F138 / ISO 5832-1 Acier Inoxydable d'Implantation (316LVM)**
- **ASTM F2229 Niobium (Non allié)**
- **Verre Borosilicate 3.3 (ISO 3585)**
- **Or Massif 14K/18K Biocompatible (Sans nickel)**

## Modules de l'Application

### 1. Lecteur de Certificats et Préréglages
Analyse les mentions sur les étiquettes, les bons de commande ou les certificats d'aciérie. Choisissez parmi 6 préréglages pour évaluer des déclarations de fournisseurs valides ou trompeuses. Évalue les seuils de composition chimique, les niveaux de biocompatibilité et les signaux d'alerte critiques.

### 2. Générateur de Questionnaire Fournisseur
Sélectionnez un matériau cible et une application clinique (perçage initial, cicatrisé, peau sensible/allergie, buccal ou ancrage sous-cutané). Génère les questions techniques précises à adresser à votre fabricant de bijoux, avec les critères de réponse acceptables et les signaux d'alerte éliminatoires. Format imprimable en un clic.

### 3. Matrice Allégation-Preuve
Recoupe 12 allégations commerciales courantes (ex. « Qualité Implantation », « Acier Chirurgical », « Hypoallergénique », « BioFlex », « Sans Nickel ») avec la documentation juridique et clinique exacte requise pour les étayer.

### 4. Outil de Comparaison Certifiée
Comparez jusqu'à 3 matériaux côte à côte selon leur analyse chimique, leur résistance mécanique, leur potentiel de corrosion galvanique et leur compatibilité de stérilisation sous des critères d'essai identiques.

### 5. Registre de Conformité Studio
Enregistrez vos contrôles de réception de matériel directement dans le coffre-fort local et privé de votre navigateur. Générez des procès-verbaux de contrôle horodatés sans aucun serveur tiers ni pistage.

## Accessibilité et Compatibilité Mobile
- Entièrement statique : fonctionne à 100 % hors ligne.
- Adapté aux smartphones (dès 360 px), tablettes et ordinateurs.
- Cibles tactiles d'au moins 44 px conçues pour une manipulation avec gants de studio.
- Contraste rigoureux (norme WCAG AA 4,5:1 minimum) en mode clair comme en mode sombre.
