Machine Maintenance Logbook: คู่มือผู้ใช้

Machine Maintenance Logbook ติดตามข้อมูลประจำตัวเครื่อง ชั่วโมงการทำงาน ค่าการปรับเทียบ รอบการบำรุงรักษา ค่าซ่อม และประวัติการตรวจสอบ สำหรับสตูดิโอสักลาย ช่างเจาะ และช่างเทคนิคอุปกรณ์ศิลปะบนร่างกาย

ใช้ทำอะไร

Machine Maintenance Logbook มีรายการอุปกรณ์ที่จัดโครงสร้างไว้สำหรับเครื่องโรตารี่ คอยล์ ปากกา และเครื่องจ่ายไฟในสตูดิโอของคุณ โดยบันทึกที่มาของอุปกรณ์ หมายเลขซีเรียล ผู้จัดจำหน่าย วันหมดอายุการรับประกัน สถานีงาน และศิลปินที่รับผิดชอบ

เครื่องมือนี้บันทึกการบำรุงรักษาอย่างต่อเนื่อง ได้แก่ การปรับเทียบแรงดันไฟฟ้า การทำความสะอาดด้วยคลื่นอัลตราโซนิก การเปลี่ยนชุดขับคาร์ทริดจ์ การตรวจมอเตอร์ การทดสอบสาย RCA การฆ่าเชื้อด้ามจับ และการเปลี่ยนชิ้นส่วน เครื่องมือจะติดตามชั่วโมงการทำงานระหว่างการตรวจสอบ แจ้งเตือนเจ้าหน้าที่เมื่อครบรอบการบำรุงรักษา รวบรวมค่าซ่อมตามเครื่องและตามปีปฏิทิน และสร้างไฟล์ปฏิทินแบบออฟไลน์สำหรับการบำรุงรักษาตามกำหนดการ

ผู้ใช้งานกลุ่มใด

  • เจ้าของและผู้จัดการสตูดิโอ ที่ติดตามเครื่องจักร รอบการบำรุงรักษาในแต่ละสถานีงาน และค่าซ่อมประจำปี
  • ศิลปินสักลายและช่างเจาะ ที่ดูแลอุปกรณ์ส่วนตัว บันทึกการปรับเทียบแรงดันไฟฟ้า และติดตามการสึกหรอของมอเตอร์
  • ผู้ดูแลด้านสุขอนามัยและเจ้าหน้าที่ความปลอดภัย ที่จัดทำเอกสารและเชื่อมโยงแฟ้มใบเสร็จฉบับกระดาษกับบันทึกอุปกรณ์แบบดิจิทัล
  • ช่างเทคนิคอุปกรณ์และผู้สร้างเครื่องจักร ที่ซ่อมบำรุงฮาร์ดแวร์ของสตูดิโอและบันทึกชั่วโมงการทำงานให้ลูกค้า

วิธีใช้งาน

การตรวจสอบการแจ้งเตือนถึงกำหนดบำรุงรักษาและการส่งออกปฏิทิน

  1. ตรวจสอบแบนเนอร์ ครบกำหนดและเกินกำหนดบำรุงรักษา เครื่องที่เกินกำหนดจะแสดง Overdue by {days} days หรือ เกินกำหนด {hours} ชั่วโมงการทำงาน
  2. กำหนดการที่อยู่ภายในสิบสี่วันจะแสดง Due in {days} days
  3. คลิก ส่งออก .ics ข้างเครื่องที่ถึงกำหนดเพื่อดาวน์โหลดการเตือนความจำในปฏิทิน
  4. เมื่อเครื่องอยู่ตามกำหนดการ แบนเนอร์จะแสดง เครื่องที่ใช้งานอยู่ทั้งหมดได้รับการบำรุงรักษาตามกำหนดแล้ว

การลงทะเบียนเครื่องในรายการอุปกรณ์

  1. เปิดแท็บ เครื่องจักร
  2. ป้อนรหัสในช่อง ชื่อ / รหัสเครื่อง ช่องนี้จำเป็นต้องกรอก
  3. ป้อนข้อมูลฮาร์ดแวร์ในช่อง หมายเลขซีเรียล รุ่น และ ผู้จัดจำหน่าย / ตัวแทนจำหน่าย
  4. บันทึกวันที่ในช่อง วันที่ซื้อ และ วันสิ้นสุดการรับประกัน
  5. เพิ่มรายละเอียดสถานที่ในช่อง สถานี / ห้อง และกำหนดศิลปินในช่อง ศิลปินที่รับผิดชอบ
  6. กำหนดเป้าหมายการบำรุงรักษาในช่อง รอบบำรุงรักษา (วัน) หรือ รอบบำรุงรักษา (ชั่วโมง)
  7. คลิก บันทึกเครื่อง เพื่อเพิ่มอุปกรณ์ลงในตารางรายการ

การจัดการสถานะเครื่องและการปลดระวาง

  1. ค้นหาอุปกรณ์ในตาราง เครื่องที่ลงทะเบียน ที่แสดง ใช้งานอยู่
  2. เมื่อจัดเก็บหรือปลดระวางอุปกรณ์ ให้คลิก ปลดระวาง ภายใต้ การดำเนินการ
  3. ยืนยันการดำเนินการ สถานะจะเปลี่ยนเป็น ปลดระวางแล้ว โดยเก็บประวัติไว้และปิดการแจ้งเตือน
  4. คลิก เปิดใช้งานอีกครั้ง เพื่อนำเครื่องกลับมาใช้งาน

การบันทึกเหตุการณ์การบำรุงรักษา

  1. เปิดแท็บ บันทึกการบำรุงรักษา
  2. เลือกอุปกรณ์ภายใต้ เลือกเครื่อง
  3. เลือกวันที่ปฏิทินในช่อง วันที่บำรุงรักษา
  4. ป้อนค่าจากมิเตอร์ในช่อง ชั่วโมงการทำงานปัจจุบัน
  5. เลือกงานภายใต้ ประเภทการบำรุงรักษา: ปรับเทียบแรงดันไฟฟ้า, ทำความสะอาดและฆ่าเชื้อ, เปลี่ยนคาร์ทริดจ์เข็ม, บำรุงรักษาเต็มรูปแบบ (ลูกปืน/มอเตอร์), ตรวจสาย / สาย RCA, ฆ่าเชื้อด้ามจับ, เปลี่ยนชิ้นส่วน หรือ อื่นๆ
  6. ป้อนข้อมูลการวินิจฉัยในช่อง แรงดันไฟฟ้าขณะทำงาน (V), ชิ้นส่วนที่เปลี่ยน, ค่าใช้จ่าย และ เลขอ้างอิงการจัดเก็บ (รายงานกระดาษ / แฟ้มใบเสร็จ)
  7. เพิ่มหมายเหตุในช่อง หมายเหตุการบำรุงรักษา แล้วคลิก เพิ่มในบันทึก

การกรองและทบทวนประวัติการบำรุงรักษา

  1. กรองรายการโดยใช้ ทุกสถานี / ห้อง, ศิลปินทุกคน, เครื่องทุกเครื่อง, ทุกประเภท หรือ สถานะ: ทั้งหมด, สถานะ: เฉพาะที่ใช้งานอยู่ และ สถานะ: เฉพาะที่ปลดระวางแล้ว
  2. คอลัมน์ ชั่วโมง (ผลต่าง) คำนวณเวลาระหว่างการตรวจสอบโดยใช้ {current} ชม. - {prev} ชม. = {delta} ชม. นับจาก{type}ครั้งล่าสุด
  3. หากต้องการลบรายการ ให้คลิก ลบ (×) แล้วยืนยัน

การวิเคราะห์ชิ้นส่วนที่เปลี่ยนและค่าใช้จ่ายในการบำรุงรักษา

  1. เปิดแท็บ ชิ้นส่วนและค่าใช้จ่าย
  2. ในส่วน ค่าใช้จ่ายรวมตามเครื่อง ให้ตรวจสอบชิ้นส่วนที่เปลี่ยนภายใต้ ชิ้นส่วนที่เปลี่ยน การคำนวณภายใต้ การคำนวณค่าใช้จ่าย และยอดรวมภายใต้ ค่าใช้จ่ายรวม
  3. ในส่วน ค่าใช้จ่ายรวมตามปี ให้ตรวจสอบจำนวนการบำรุงรักษาและค่าใช้จ่ายรายปี

การสร้างและกู้คืนไฟล์สำรองข้อมูล

  1. เปิดแท็บ สำรองและกู้คืนข้อมูล
  2. คลิก ส่งออกไฟล์สำรอง JSON เพื่อดาวน์โหลดไฟล์สำรองฐานข้อมูลแบบออฟไลน์
  3. คลิก กู้คืนไฟล์สำรอง JSON เพื่อนำเข้าไฟล์สำรองที่บันทึกไว้ก่อนหน้า
  4. คลิก ล้างข้อมูลทั้งหมด เพื่อลบบันทึกในเครื่อง

สิ่งที่เครื่องมือนี้ไม่ทำ

  • ไม่คำนวณระยะเวลาคืนทุนของอุปกรณ์ทุนหรือจุดคุ้มทุนรายชั่วโมง การวิเคราะห์ทางการเงินเหล่านั้นเป็นหน้าที่ของ Equipment ROI Calculator
  • ไม่เปรียบเทียบค่าเช่าพื้นที่ห้องในสตูดิโอ อัตราค่าบริการรายชั่วโมง หรือส่วนแบ่งค่าคอมมิชชันของศิลปิน การประเมินราคาสตูดิโอเป็นหน้าที่ของ Studio Pricing Benchmark
  • ไม่บันทึกรอบการฆ่าเชื้อด้วยไอน้ำในออโตเคลฟ (autoclave) การทดสอบสปอร์ หรือแถบตัวบ่งชี้ทางเคมี การบันทึกออโตเคลฟเป็นหน้าที่ของ Autoclave & Sterilization Calculator
  • ไม่ติดตามหมายเลขชุดการผลิตของเครื่องประดับเจาะปลอดเชื้อ รายงานการทดสอบวัสดุจากโรงงาน (mill test reports) หรือมาตรฐานโลหะผสม ใบรับรองจากโรงงานและมาตรฐานโลหะผสมจะตรวจสอบใน Biocompatibility Material Checker

ข้อมูลของคุณถูกเก็บไว้ที่ใด

รายการอุปกรณ์และบันทึกการบำรุงรักษาของคุณถูกเก็บไว้ในเว็บเบราว์เซอร์บนอุปกรณ์ของคุณเท่านั้น แอปพลิเคชันจัดเก็บข้อมูลใน localStorage ของเบราว์เซอร์ และไม่เคยส่งรายละเอียดเครื่อง หมายเลขซีเรียล ตัวเลขทางการเงิน หรือชื่อศิลปินไปยัง Poli International หรือเซิร์ฟเวอร์ระยะไกลใด ๆ

เนื่องจากบันทึกถูกเก็บไว้ในเครื่อง การล้างข้อมูลเว็บไซต์ในเบราว์เซอร์ การล้างแคชของเว็บไซต์ หรือการใช้หน้าต่างท่องเว็บแบบส่วนตัวชั่วคราวจะลบบันทึกของคุณ ควรดาวน์โหลดไฟล์สำรองเป็นประจำผ่าน ส่งออกไฟล์สำรอง JSON ก่อนทำความสะอาดระบบ

ไฟล์ส่งออก JSON ฉบับสมบูรณ์มีเวอร์ชันสคีมาของแอปพลิเคชัน เวลาที่ส่งออก โปรไฟล์เครื่องที่ลงทะเบียนไว้ และบันทึกการบำรุงรักษา ส่วนไฟล์ส่งออก CSV มีข้อมูลตารางที่กรองแล้วซึ่งจัดรูปแบบสำหรับโปรแกรมสเปรดชีต

การพิมพ์และการส่งออก

  • สเปรดชีต CSV: ในแท็บ บันทึกการบำรุงรักษา คลิก ส่งออก CSV เพื่อดาวน์โหลดไฟล์ตารางที่มีวันที่ ชื่อเครื่อง สถานี ศิลปิน ประเภท ชั่วโมงการทำงาน แรงดันไฟฟ้า ชิ้นส่วน ค่าใช้จ่าย เลขอ้างอิงการจัดเก็บ และหมายเหตุ
  • การเตือนความจำในปฏิทิน: ใน ครบกำหนดและเกินกำหนดบำรุงรักษา หรือ เครื่องจักร คลิก ส่งออก .ics เพื่อดาวน์โหลดไฟล์ปฏิทินสำหรับ Google Calendar, Apple Calendar หรือ Microsoft Outlook
  • ไฟล์สำรอง JSON: ในแท็บ สำรองและกู้คืนข้อมูล คลิก ส่งออกไฟล์สำรอง JSON เพื่อสร้างไฟล์สำรองฐานข้อมูลฉบับสมบูรณ์สำหรับการย้ายสตูดิโอหรือการสำรองข้อมูล
  • สำเนากระดาษ: ใช้ฟังก์ชันพิมพ์ของเบราว์เซอร์ (Ctrl+P หรือ Cmd+P) เพื่อพิมพ์ตารางกระดาษที่อ่านง่ายสำหรับแฟ้มตรวจสอบในสถานที่จริง

คำถามและคำตอบ

ฉันจะทราบได้อย่างไรว่าเครื่องสักลายถึงกำหนดบำรุงรักษา

แอปพลิเคชันประเมินเครื่องที่ใช้งานอยู่เทียบกับรอบการบำรุงรักษาที่กำหนดไว้ เมื่อจำนวนวันที่ผ่านไปหรือชั่วโมงการทำงานเกินเกณฑ์ที่กำหนด แบนเนอร์ด้านบนจะแจ้งว่าเครื่องนั้นเกินกำหนด หากการบำรุงรักษาที่กำหนดไว้อยู่ภายในสิบสี่วัน แบนเนอร์จะแจ้งเตือนว่าใกล้ถึงกำหนดบำรุงรักษา

ฉันติดตามรอบการบำรุงรักษาโดยใช้ชั่วโมงการทำงานแทนวันตามปฏิทินได้ไหม

ได้ โปรไฟล์เครื่องรองรับรอบการบำรุงรักษาที่วัดเป็นชั่วโมงการทำงาน วันตามปฏิทิน หรือทั้งสองอย่าง เมื่อคุณบันทึกชั่วโมงการทำงานระหว่างการบำรุงรักษา ซอฟต์แวร์จะติดตามการใช้งานและแจ้งเตือนเมื่อถึงเป้าหมายชั่วโมง

บันทึกการบำรุงรักษาจะเป็นอย่างไรเมื่อเครื่องถูกปลดระวาง

การปลดระวางอุปกรณ์จะเก็บบันทึกการบำรุงรักษา การคำนวณค่าใช้จ่าย และการปรับเทียบในอดีตทั้งหมดไว้ เครื่องที่ปลดระวางจะถูกนำออกจากการแจ้งเตือนการบำรุงรักษาที่ใช้งานอยู่ แต่ยังเข้าถึงได้โดยใช้ตัวกรองสถานะ

ข้อมูลการบำรุงรักษาเครื่องของฉันถูกเก็บไว้ที่ใด

ข้อมูลทั้งหมดถูกบันทึกไว้ในที่เก็บข้อมูลของเบราว์เซอร์บนอุปกรณ์ปัจจุบันของคุณ ไม่มีโปรไฟล์เครื่อง หมายเลขซีเรียล ค่าใช้จ่าย หรือชื่อศิลปินที่ถูกส่งผ่านเครือข่ายหรือจัดเก็บบนเซิร์ฟเวอร์ของ Poli International

ฉันจะย้ายบันทึกเครื่องไปยังคอมพิวเตอร์หรือแท็บเล็ตเครื่องอื่นได้อย่างไร

เปิด สำรองและกู้คืนข้อมูล บนคอมพิวเตอร์เครื่องปัจจุบันแล้วคลิก ส่งออกไฟล์สำรอง JSON เพื่อบันทึกไฟล์ฐานข้อมูล ย้ายไฟล์นี้ไปยังอุปกรณ์ใหม่ เปิดเครื่องมือบนอุปกรณ์นั้น คลิก กู้คืนไฟล์สำรอง JSON แล้วเลือกไฟล์

ช่องเลขอ้างอิงการจัดเก็บใช้ทำอะไร

ช่องเลขอ้างอิงการจัดเก็บเชื่อมโยงรายการดิจิทัลกับแฟ้มเอกสารกระดาษ แฟ้มใบเสร็จ หรือแฟ้มใบแจ้งหนี้ในสตูดิโอ การบันทึกเลขใบแจ้งหนี้หรือตำแหน่งแฟ้มช่วยให้เจ้าหน้าที่สตูดิโอจัดทำใบเสร็จหรือบันทึกการตรวจสอบในกระดาษระหว่างการตรวจสอบได้

ฉันจะส่งออกวันที่บำรุงรักษาที่กำลังจะมาถึงไปยังปฏิทิน Google หรือ Apple ได้ไหม

ได้ การคลิก ส่งออก .ics ข้างเครื่องใดก็ได้ที่ถึงกำหนดจะดาวน์โหลดไฟล์เหตุการณ์ iCalendar มาตรฐาน คุณสามารถนำเข้าไฟล์นี้ไปยัง Google Calendar, Apple Calendar หรือ Outlook เพื่อตั้งการเตือนความจำการบำรุงรักษาในเครื่องได้

บันทึกคำนวณชั่วโมงการทำงานส่วนต่างระหว่างการบำรุงรักษาอย่างไร

เมื่อคุณบันทึกชั่วโมงการทำงาน ระบบจะค้นหารายการก่อนหน้าของเครื่องนั้นและประเภทการบำรุงรักษานั้น แล้วนำค่าที่อ่านได้ก่อนหน้าไปลบออกจากค่าปัจจุบัน และแสดงชั่วโมงการทำงานที่เกิดขึ้นระหว่างการตรวจสอบสองครั้ง

ข้อจำกัด

Machine Maintenance Logbook ให้บันทึกการบริหารจัดการของประวัติการบำรุงรักษาในสตูดิโอ แต่ไม่สามารถประเมินสภาพทางกายภาพของฮาร์ดแวร์ได้ ซอฟต์แวร์ไม่สามารถตรวจจับความล้าของมอเตอร์ภายใน ความฝืดของลูกปืน การลัดวงจรทางไฟฟ้า การคลายตัวของแรงตึงสปริง หรือประสิทธิภาพการฆ่าเชื้อของออโตเคลฟ

ศิลปินสักลาย ช่างเจาะ และเจ้าของสตูดิโอยังคงต้องรับผิดชอบแต่เพียงผู้เดียวในการตรวจสอบเครื่องจักรด้วยตนเอง ทดสอบความปลอดภัยทางไฟฟ้า ตรวจสอบข้อกำหนดของผู้ผลิต และปฏิบัติตามมาตรฐานสุขอนามัยของสตูดิโอ บันทึกดิจิทัลช่วยเสริมความรอบคอบในการทำงานในสตูดิโอ แต่ไม่สามารถแทนที่การตรวจสอบทางกายภาพโดยตรงจากช่างเทคนิคอุปกรณ์ที่มีคุณสมบัติเหมาะสม

ใช้เครื่องมือ

เปิด Machine Maintenance Logbook: คู่มือผู้ใช้ ทุกอย่างทำงานในเบราว์เซอร์ของคุณ ไม่มีข้อมูลใดที่คุณป้อนถูกส่งออกไปที่ใด
