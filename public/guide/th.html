คู่มือผู้ใช้ Studio CRM

Studio CRM ทำงานบนคอมพิวเตอร์เครื่องเดียวในสตูดิโอของคุณ พนักงานเปิดใช้งานผ่านเว็บเบราวเซอร์บนคอมพิวเตอร์เครื่องนั้น หรือบนอุปกรณ์ใดก็ได้ในเครือข่ายของสตูดิโอ ข้อมูลของคุณจะอยู่ในไฟล์บนคอมพิวเตอร์เครื่องนั้นเท่านั้น ไม่มีการส่งข้อมูลใด ๆ ไปยัง Poli International

การติดตั้งและเริ่มใช้งาน

  1. ดาวน์โหลดไฟล์ ZIP ของ Studio CRM สำหรับคอมพิวเตอร์ของคุณ (Windows, Mac หรือ Linux) จากหน้า Studio CRM มี Node.js รวมอยู่ในไฟล์แล้ว ไม่ต้องติดตั้งอะไรเพิ่ม
  2. แตกไฟล์ ZIP แล้ววางโฟลเดอร์ studio-crm ไว้ในที่ที่จะเก็บไว้ถาวร เช่น ในโฟลเดอร์ Documents
  3. ดับเบิลคลิกที่ Start Studio CRM (Start Studio CRM.bat บน Windows, Start Studio CRM.command บน Mac, ./start-studio-crm.sh บน Linux) บน Mac ครั้งแรกให้คลิกขวาแล้วเลือก Open
  4. เบราวเซอร์จะเปิดที่ http://localhost:3000 ให้เปิดหน้าต่างที่ปรากฏขึ้นค้างไว้ตลอดเวลาที่ใช้ CRM หากปิดหน้าต่างนั้น CRM จะหยุดทำงาน อุปกรณ์อื่นให้ใช้ที่อยู่เครือข่ายของคอมพิวเตอร์แทน localhost โดยมี :3000 ต่อท้าย

หากคุณดาวน์โหลดซอร์สโค้ด ให้ติดตั้ง Node.js เวอร์ชัน 22 หรือใหม่กว่า แล้วรัน npm install หนึ่งครั้ง ตามด้วย npm start สำหรับ Docker: docker compose up -d

เมื่อต้องการอัปเดต ให้ดาวน์โหลดไฟล์ ZIP ใหม่ แตกไฟล์ลงในโฟลเดอร์ใหม่ แล้วคัดลอกโฟลเดอร์ data ของคุณจากโฟลเดอร์เดิมไปยังโฟลเดอร์ใหม่

หากต้องการใช้พอร์ตอื่น ให้กำหนดค่า PORT ในไฟล์ .env (คัดลอกจาก .env.example) และกำหนดค่า STUDIO_MANAGER_EMAIL ไว้ที่นั่นด้วย เพื่อให้การแจ้งเตือนส่งถึงคุณ

การเริ่มใช้งานครั้งแรก: ข้อมูลตัวอย่าง

การติดตั้งใหม่จะเปิดพร้อมข้อมูลตัวอย่างของลูกค้า นัดหมาย สต็อก และพนักงาน เพื่อให้คุณลองใช้งานได้ทุกหน้าจอ เมื่อพร้อมสำหรับการทำงานจริง ให้คลิก เริ่มต้นด้วยสตูดิโอเปล่า บนแดชบอร์ด การทำเช่นนี้จะลบข้อมูลตัวอย่างทั้งหมด และคงรายการบริการ หมวดหมู่ เทมเพลต สถานี และการตั้งค่าไว้ การกระทำนี้ไม่สามารถย้อนกลับได้

ภาษา

เลือกภาษาอังกฤษ ฝรั่งเศส อิตาลี เยอรมัน สเปน เนเธอร์แลนด์ โปรตุเกส หรือไทย จากเมนูภาษาด้านบน เครื่องมือ Poli ภายใน CRM จะเปิดในภาษาเดียวกันเมื่อรองรับภาษานั้น (เครื่องมือที่ไม่มีภาษาไทยจะเปิดเป็นภาษาอังกฤษ)

การตั้งค่าสตูดิโอ

เปิด การตั้งค่า เพื่อกรอกราคา เงื่อนไขมัดจำ อัตราภาษี (VAT) นโยบายการแก้ไขงาน และระดับสต็อกขั้นต่ำ ตัวประเมินราคา ใบเสนอราคา และใบแจ้งหนี้จะใช้ตัวเลขเหล่านี้ ดังนั้นให้กำหนดค่าก่อน ส่งออก CSV จะดาวน์โหลดรายการราคาของคุณ แก้ไขไฟล์นั้นแล้วใช้ นำเข้า CSV เพื่อโหลดกลับเข้าไป คุณยังสามารถอัปโหลดโลโก้สตูดิโอของคุณได้ด้วย ซึ่งจะแสดงที่แถบด้านบน

ลูกค้า

ลูกค้า แสดงรายชื่อทุกคนพร้อมข้อมูลติดต่อ อาการแพ้และบันทึกทางการแพทย์ แบบฟอร์มยินยอมที่ลงนามแล้ว และยอดใช้จ่ายรวม ใช้ ลูกค้าใหม่ เพื่อเพิ่มลูกค้า การค้นหาจะกรองรายการทันทีที่คุณพิมพ์ ดูโปรไฟล์ จะเปิดข้อมูลฉบับเต็ม ในโปรไฟล์ แก้ไขข้อมูลลูกค้า ใช้เปลี่ยนรายละเอียด และ ลบ ใช้ลบลูกค้า โปรไฟล์ยังแสดงนัดหมาย บันทึกของพนักงาน ใบยินยอมที่ลงนามแล้ว แบบฟอร์มยินยอมที่บันทึกไว้ และรูปผลงาน หากต้องการเพิ่มลูกค้าหลายคนพร้อมกัน ให้เปิด การตั้งค่า แล้วเลือก Import Data และวางรายการที่บรรทัดแรกเป็น name,email,phone,allergies,notes

พนักงาน

คลิกปุ่มพนักงานที่มุมขวาบนเพื่อดูทีมของคุณ เพิ่มพนักงาน ใช้เพิ่มคน แก้ไข ใช้เปลี่ยนรายละเอียด และ นำออก ใช้นำคนออกจากทีม เลือก จะแสดงชื่อของคนนั้นบนแถบด้านบน เพื่อให้ทุกคนเห็นว่าใครกำลังใช้หน้าจอ ไม่มีรหัสผ่านและไม่มีระดับสิทธิ์การเข้าถึง พนักงานใหม่เลือกได้ทันทีในทุกที่ที่ต้องเลือกช่าง เช่น ตอนจองนัดหมาย

แท็บเล็ต โทรศัพท์ และรหัสผ่านของสตูดิโอ

อุปกรณ์อื่นในสตูดิโอเปิด CRM ด้วยที่อยู่ที่แสดงในหน้าต่างที่ใช้เริ่มโปรแกรม แท็บเล็ตหรือโทรศัพท์ที่ต้องใช้กล้อง (ตัวสแกน) ต้องใช้ที่อยู่ที่ขึ้นต้นด้วย https:// และลงท้ายด้วย :3443 ครั้งแรกเบราว์เซอร์จะเตือนว่าการเชื่อมต่อไม่เป็นส่วนตัว เพราะใบรับรองสร้างโดยคอมพิวเตอร์ของคุณเอง ให้เลือกขั้นสูง แล้วเลือกดำเนินการต่อ หากใช้ที่อยู่ http:// แบบธรรมดา ทุกอย่างใช้ได้ยกเว้นกล้อง

หากต้องการกันคนอื่นในเครือข่ายเดียวกันออก ให้เปิด การตั้งค่า แล้วตั้ง รหัสผ่านของสตูดิโอ จากนั้นทุกอุปกรณ์จะลงชื่อเข้าใช้หนึ่งครั้ง รหัสผ่านนี้ใช้ร่วมกันทั้งสตูดิโอ ไม่ใช่คนละรหัส หากลืมรหัสผ่าน ให้สร้างไฟล์เปล่าชื่อ reset-password.txt ในโฟลเดอร์ data แล้วเริ่ม CRM ใหม่

นัดหมายและการจัดตารางเวลา

นัดหมายใหม่ ใช้จองนัดหมายครั้งเดียว พร้อมช่างศิลป์ สถานีทำงาน ราคา และมัดจำ สำหรับงานที่ต้องทำหลายครั้ง ตัวจัดตารางอัตโนมัติ จะค้นหาช่วงเวลาว่างของช่างศิลป์ในวันที่เลือก และจองได้สูงสุดหกครั้ง โดยเว้นระยะห่างตามจำนวนสัปดาห์ที่กำหนด แดชบอร์ดจะแสดงตัวเลขของวันนี้ นัดหมายที่กำลังจะมาถึง สถานะของสถานีทำงาน และสต็อกที่เหลือน้อย ปฏิทินแสดงนัดหมายที่จองไว้ทั้งหมด โดยเรียงนัดที่กำลังจะถึงก่อน เสร็จสิ้น ใช้ทำเครื่องหมายว่างานเสร็จแล้ว เพื่อให้นับรวมในการวิเคราะห์ระยะเวลา และ นำออก ใช้ลบนัดหมาย

แบบฟอร์มยินยอมแบบดิจิทัล

เปิดแบบฟอร์มยินยอม เลือกลูกค้าจากรายการ (ข้อมูลอาการแพ้จะถูกกรอกให้อัตโนมัติ) ยืนยันการตรวจสอบอายุ แล้วให้ลูกค้าลงนามบนแท็บเล็ต แบบฟอร์มยินยอมจะถูกบันทึกพร้อมภาพลายเซ็น จะไม่สามารถบันทึกได้หากไม่มีลูกค้าและลายเซ็น

หากต้องการให้ลูกค้ากรอกแบบฟอร์มยินยอมบนแท็บเล็ต ให้เปิด ลูกค้า ตัวสร้างแบบฟอร์มยินยอม ตัวอย่างแบบฟอร์ม แล้วเลือกโหมดคีออสก์สำหรับแท็บเล็ต ลูกค้าตอบทีละส่วนต่อหนึ่งหน้าจอ ลงนามในหน้าสุดท้าย แล้วแตะปุ่มเพื่อเสร็จสิ้น แบบฟอร์มจะถูกบันทึกพร้อมลายเซ็นและดาวน์โหลดไฟล์ PDF หากยังไม่ได้เลือกลูกค้าไว้ก่อน ระบบจะสร้างลูกค้าใหม่จากชื่อ อีเมล โทรศัพท์ และวันเกิดในแบบฟอร์ม แบบฟอร์มที่บันทึกไว้อยู่ในโปรไฟล์ของลูกค้า ใต้ ใบยินยอม และ ดูคำตอบ จะแสดงทุกคำตอบ แบบฟอร์มที่แก้ไขในตัวสร้างแบบฟอร์มจะถูกบันทึกไว้กับข้อมูลของสตูดิโอ แท็บเล็ตจึงแสดงแบบฟอร์มเดียวกับคอมพิวเตอร์ที่คุณใช้แก้ไข

ข้อความ: CRM เตรียมให้ คุณเป็นผู้ส่ง

Studio CRM ไม่ส่งอีเมล SMS หรือข้อความแชทด้วยตัวเอง เมื่อคุณเตรียมอีเมลการดูแลหลังทำ ข้อความเตือน หรือใบสั่งซื้อจากซัพพลายเออร์ จะมีแผง ข้อความพร้อมแล้ว ปรากฏขึ้น คลิก อีเมล WhatsApp หรือ LINE เพื่อเปิดในแอปของคุณเองโดยมีข้อความกรอกไว้แล้ว จากนั้นกดส่งที่นั่น หรือคลิก คัดลอก

สต็อก เครื่องสแกน และใบสั่งซื้อ

คลังสินค้า ติดตามจำนวน ล็อต วันหมดอายุ และซัพพลายเออร์ สินค้าที่อยู่ที่ระดับสั่งซื้อซ้ำหรือต่ำกว่าจะถูกนับเป็นสต็อกเหลือน้อย

เครื่องสแกนใน บันทึกกิจกรรม ใช้กล้องของอุปกรณ์ สแกน SKU ของสต็อกหรือหมายเลขล็อตเพื่อดูสินค้า หรือสแกนรหัส CLIENT-<number> เพื่อเปิดข้อมูลลูกค้า คุณยังสามารถสแกนรหัสจากภาพถ่ายได้ด้วย รหัสที่ไม่รู้จักจะถูกแสดงไว้ใน บันทึกข้อผิดพลาด

ใบสั่งซื้อ แสดงรายชื่อซัพพลายเออร์และสินค้าที่สต็อกเหลือน้อยของแต่ละราย สร้างหมายเลขใบสั่งซื้อ ดาวน์โหลด PDF และเตรียมอีเมลสั่งซื้อ

แกลเลอรี

ผลงานพอร์ตโฟลิโอ เก็บภาพผลงานที่เสร็จแล้ว เชื่อมโยงกับลูกค้าและช่างศิลป์ แผ่นแฟลช เก็บลายที่มีราคาและมัดจำ ให้ทำเครื่องหมายว่าถูกจองเมื่อลูกค้าจองลาย แชร์ จะเตรียมข้อความสำหรับ WhatsApp LINE X หรืออีเมล เมนูแชร์ของโทรศัพท์อาจรวมภาพถ่ายด้วย

เงินและพนักงาน

เครื่องคำนวณทิป แบ่งทิปเป็น 80% ให้ช่างศิลป์ 15% ให้ผู้ฝึกงาน 5% ให้พนักงานต้อนรับ และบันทึกไว้ พนักงานลงเวลาเข้าและออกงานด้วยปุ่มกะทำงาน การส่งออกข้อมูลจะให้บันทึกกิจกรรม สต็อกเหลือน้อย กะทำงาน และระยะเวลาของแต่ละครั้ง เป็นไฟล์ CSV หรือ PDF ในปฏิทิน หน้าต่างกะทำงานจะแสดงว่าพนักงานอยู่ในกะหรือไม่ และ ตารางกะ จะแสดงกะที่วางแผนไว้ เลือกพนักงาน วันที่ และเวลา แล้วกด เพิ่มกะ การส่งออกตารางกะ และการส่งออกรายการสต็อกในหน้าสต็อก จะบันทึกไฟล์ CSV หรือ PDF ลงในโฟลเดอร์ดาวน์โหลดของคุณ

บันทึกด้านการปฏิบัติตามข้อกำหนด

รายการตรวจสอบก่อนปิดร้าน บันทึกว่ารายการใดทำแล้ว หัวหน้างานที่รับผิดชอบ หมายเลขรอบของหม้อนึ่งฆ่าเชื้อ และบันทึกของคุณ คลังข้อมูลหม้อนึ่งฆ่าเชื้อ แสดงรายการรอบการฆ่าเชื้อ และแดชบอร์ดจะเตือนเกี่ยวกับสต็อกที่หมดอายุแล้ว ข้อมูลเหล่านี้เป็นบันทึกของคุณเอง ให้ตรวจสอบกฎของหน่วยงานสาธารณสุขในพื้นที่ของคุณว่าต้องเก็บอะไรไว้บ้าง

เครื่องมือ Poli

หน้าจอ เครื่องมือ เปิดเครื่องมือของ Poli International (ตารางการดูแลหลังทำ ตัวสร้างแบบฟอร์มยินยอม ตัวแปลงเกจ ตัวประเมินราคา และอื่น ๆ) ภายใน CRM

การสำรองข้อมูล

ข้อมูลทั้งหมดจะถูกจัดเก็บใน data/studio_crm.sqlite (หรือพาธที่กำหนดไว้ใน SQLITE_DB_PATH) คัดลอกไฟล์นั้นเพื่อสำรองข้อมูลของสตูดิโอ ปุ่มสแนปช็อตยังเขียนสำเนาไปยัง storage/backups/ ด้วย
