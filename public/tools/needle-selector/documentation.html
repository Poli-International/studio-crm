Tattoo Needle Selector: user guide

The Tattoo Needle Selector is an interactive configuration advisor, blister pack code decoder, and side-by-side needle grouping comparator for professional tattoo artists and apprentices.

What it is for

The Tattoo Needle Selector provides technical clarity on tattoo needle groupings, tapers, diameters, and operating parameters. Tattoo needles arrive in dozens of packaging codes, from micro-liners to broad magnums. Selecting the wrong needle grouping or running incorrect voltage causes tissue trauma, pigment blowout, or poor saturation.

This tool translates design requirements into practical hardware choices. Artists select a technique, style, and skin condition to receive needle configurations and machine settings. The tool also decodes blister pack codes, displays geometric cross-sections, compares clusters side by side, and provides a reference matrix.

Who it is for

  • Professional tattoo artists verifying cluster diameters, effective skin coverage, and voltage ranges.
  • Apprentice tattooers learning the mechanical differences between liners, shaders, magnums, and flats.
  • Studio owners and mentors standardizing needle selection guidelines across their studio.
  • Guest artists navigating unfamiliar blister pack codes across international cartridge brands.

How to use it

Quick Selector

  1. Click Quick Selector in the main navigation.
  2. Under Find Your Optimal Needle, choose options from Technique (-- Select Technique --), Artistic Style (-- Select Style --), and Skin Type (-- Select Skin Type --).
  3. Click Get Recommendation to generate technical guidance, or click Reset to clear selections.
  4. Review the Recommended Needle Configuration card displaying Needle Count, Configuration Type, Best For, and Operating Guidelines (Voltage, Machine Speed, Hanging Depth).
  5. Inspect the interactive Needle cross section diagram, Technical Guidance, and Viable Alternatives.
  6. Click Copy Code to copy the recommended configuration code directly to your clipboard.

Code Decoder

  1. Click Code Decoder in the main navigation.
  2. Locate the Packaging Code input field in the Blister-Pack Code Decoder panel.
  3. Enter any standard needle code (such as 1209RL, 11M1, 15RS, or 7CM) and click Decode Needle.
  4. Review the Needle Breakdown displaying Blister Gauge:, Number of micro-needles in cluster, Cluster grouping configuration, Pattern, and Cluster Diameter.
  5. Examine Optimal Applications, Recommended Machine Settings, Clinical Advantages, Technique Considerations, and the Decoded cluster diagram.

Needle Comparator

  1. Click Needle Comparator in the main navigation.
  2. Under First Needle, select your initial configuration from the dropdown menu (-- Choose a Needle --).
  3. Under Second Needle, choose a second configuration, and optionally select a third under Third Needle (Optional).
  4. Click Compare Configurations to render side-by-side cluster cross-sections, Effective Coverage, Arrangement Pattern, Working Voltage, and Primary Uses.

Technical Reference

  1. Click Technical Reference in the main navigation.
  2. Under Technical Needle Matrix, select any tab: Round Liners (RL), Round Shaders (RS), Weaved Magnums (M1), Curved Magnums (CM), or Flats (F).
  3. Browse the table to inspect needle counts, cluster diameters, taper lengths, recommended voltages, and target techniques.
  4. Click Hide Chart or Show Chart to toggle the diameter comparison chart, or click any needle row to inspect it in the Code Decoder.

Language Selection

  1. Locate the language selection dropdown in the header or embed toolbar.
  2. Select any of the seven supported languages: English (EN), Français (FR), Italiano (IT), Deutsch (DE), Español (ES), Nederlands (NL), or Português (PT).
  3. The interface immediately translates all navigation links, form labels, recommendations, decoder readouts, comparator cards, and reference matrices.
  4. Your chosen language preference is saved in your browser's localStorage for all subsequent sessions.

Dark and Light Theme Toggle

  1. Click the contrast theme button (◐) in the top navigation bar.
  2. The interface switches between high-contrast dark mode and clean light mode, adhering to accessibility standards across all views.
  3. Your theme setting is remembered across sessions in localStorage.

Embed Tool

  1. Click Embed Tool in the application header.
  2. In the Embed Needle Selector on Your Studio Website modal, review the HTML Embed Snippet (Self-Contained Responsive Iframe).
  3. Click Copy Snippet to copy the embed markup to your clipboard.
  4. Paste the snippet into your website editor, then click Close to dismiss the modal.

Where your data lives

All calculations, needle decodings, and comparison views run entirely in your web browser on your local device. No selections, searches, or inputs are transmitted across the network to Poli International or any third party.

Your interface language and theme preference are stored locally through localStorage. Clearing browser cache or site data resets these preferences to default. Copying a needle code or embed snippet places plain text onto your local clipboard without creating external records.

Printing and exporting

You can print any view of the tool using your browser print shortcut (Ctrl+P on Windows/Linux, Cmd+P on macOS). The print stylesheet hides navigation headers, theme buttons, and search forms while formatting reference tables and comparison cards cleanly.

To export needle configurations into procedure notes or training sheets, use Copy Code in the Quick Selector or Copy Snippet in the Embed Tool. The copied text contains standard configuration codes that paste directly into any document or messaging app.

Questions and answers

What is the difference between a round liner and a round shader?

A round liner solders needle pins tightly into a concentrated point for crisp outlines and fine detail work. A round shader solders pins in a circular arrangement with wider spacing between the tips. This looser spacing disperses ink gently into the dermis, making round shaders suitable for small-area blending, soft shading, and bold traditional lines.

What do the numbers on a tattoo needle blister pack mean?

A code such as 1209RL indicates wire gauge, pin count, and grouping configuration. The first two digits show wire diameter, where 12 represents #12 gauge (0.35 mm standard wire) and 10 represents #10 gauge (0.30 mm bugpin). The next two digits show the pin count (09 for nine pins), and the letters indicate the grouping (RL for Round Liner).

When should an artist choose a curved magnum over a standard magnum?

Curved magnums feature pins soldered along an arched outer profile. This curvature keeps the outer pins from gouging the skin during angled passes, producing smooth gradients without harsh edge lines. Standard weaved magnums have a flat edge that delivers saturated ink deposits, making them preferable for solid color packing and heavy blackwork.

Which needle gauge is best for fine line tattooing?

A #10 gauge (0.30 mm) or #08 gauge (0.25 mm bugpin) round liner is typically best for fine line work. Narrower pins create smaller puncture marks, cause less tissue trauma, and afford tighter control during delicate single-pass lines. Standard #12 gauge needles deliver greater ink volume per hit but yield a broader stroke width.

What needle configuration minimizes skin trauma in realism portraits?

Realism portraiture commonly uses curved magnums and small round shaders equipped with medium or long tapers. The arched edge of a curved magnum blends tone smoothly without leaving sharp borders across facial contours. Long tapers puncture the dermis with minimal friction, reducing tissue swelling during multi-layer shading.

How do I embed the Tattoo Needle Selector on my studio website?

Click Embed Tool in the top navigation bar to open the embed modal window. Copy the pre-built iframe snippet and paste it directly into your website HTML or content management system. The embed is fully responsive, contains no external script dependencies, and works across desktop and mobile browsers.

Does the Tattoo Needle Selector store my studio data or client details?

The tool does not collect, record, or transmit any client information or studio data. All configuration queries and comparison calculations execute entirely inside local browser memory. No information ever leaves your device, guaranteeing total privacy.

Limits

The Tattoo Needle Selector provides baseline technical guidance from established professional tattooing practice. It cannot evaluate client skin elasticity, dermal thickness variations, anatomical contours, or scar tissue.

The tool cannot detect machine motor torque, stroke length, needle throw, taper sharpness, or hand speed. Every recommended voltage and configuration serves as a starting point. The licensed tattoo artist holding the machine assesses skin response in real time and makes all final technical decisions.
