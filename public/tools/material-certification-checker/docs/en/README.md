# Material Certification Decoder: User & Reference Manual (English)

Poli International Professional Body Jewelry Standards

## Overview
The Material Certification Decoder is a clinical reference tool designed for body piercing professionals, quality auditors, and consumers. It demystifies metallurgical standards (ASTM, ISO), medical polymer evaluations (USP Class VI), and regulatory compliance directives (EU REACH Entry 27).

Biocompatible implant-grade materials recognized by international standards include:
- **ASTM F136 / ISO 5832-3 Titanium (Ti-6Al-4V ELI)**
- **BioFlex® Medical PP-R Copolymer (USP Class VI / ISO 10993)**
- **ASTM F138 / ISO 5832-1 Implant Stainless Steel (316LVM)**
- **ASTM F2229 Niobium (Unalloyed)**
- **Borosilicate Glass 3.3 (ISO 3585)**
- **Solid 14K / 18K Biocompatible Gold**

## Tool Modules

### 1. Certificate Reader & Preset Phrasing
Inspects label text, purchase orders, or mill test certificates. Select from 6 preconfigured presets to test valid and invalid supplier statements. Evaluates chemical composition thresholds, biocompatibility tiers, and critical red flags.

### 2. Supplier Question Sheet Generator
Select a target material and an intended clinical procedure (initial piercing, healed, sensitive tissue, oral, or subdermal anchor). Generates the exact technical questions to send to your jewelry manufacturer, along with acceptable response criteria and disqualifying red flags. Includes direct print capabilities.

### 3. Claim-to-Evidence Matrix
Cross-references 12 common commercial claims (e.g., "Implant Grade", "Surgical Steel", "Hypoallergenic", "BioFlex", "Nickel Free") with the exact legal and clinical documentation required to prove them.

### 4. Certified Material Comparison Tool
Compare up to 3 materials side-by-side across chemical analysis, mechanical strength, galvanic corrosion potential, and sterilization compatibility under identical testing criteria.

### 5. Dated Studio Compliance Records Vault
Save material receiving inspections directly into your browser's private local vault. Generate timestamped audit records for studio files without cloud servers or tracking.
