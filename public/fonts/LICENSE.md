# Bundled fonts

The CRM runs offline, so its fonts ship with it.

- Satoshi (satoshi-*.woff2), by Indian Type Foundry, from Fontshare: free for personal and commercial use under the Fontshare EULA (https://www.fontshare.com/licenses/itf-ffl).
- JetBrains Mono (jetbrains-mono-*.woff2), by JetBrains: SIL Open Font License 1.1 (https://github.com/JetBrains/JetBrainsMono/blob/master/OFL.txt). Files from @fontsource/jetbrains-mono 5.0.20 (latin subset).

Thai text falls back to Noto Sans Thai or the system Thai font.
