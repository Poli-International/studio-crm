Piercing Angle & Depth Guide: User Guide

มุมทางเข้าและความหนาของเนื้อเยื่อกำหนดความยาวและทิศทางของช่องเจาะอย่างไร และวิธีใช้แต่ละส่วนของเครื่องมือ

เอกสารอ้างอิงฟรีสำหรับช่างเจาะร่างกายที่ผ่านการฝึกอบรมและลูกค้าที่รับทราบข้อมูล แสดงให้เห็นว่ามุมทางเข้าและความหนาของเนื้อเยื่อกำหนดความยาวและทิศทางของช่องเจาะอย่างไร และเหตุใดช่องที่เอียงทำให้เครื่องประดับวางตัวไม่สม่ำเสมอ

เผยแพร่โดย Poli International เครื่องมือออนไลน์: https://poliinternational.com/piercing-angle-guide/

คู่มือนี้เป็นเอกสารอ้างอิง ไม่ได้แทนที่การฝึกปฏิบัติจริง และไม่ได้ตัดสินว่าการเจาะเหมาะกับบุคคลใดบุคคลหนึ่งหรือไม่

การเลือกตำแหน่ง

เลือกตำแหน่งจากปุ่มต่าง ๆ (กลุ่มหู ใบหน้า ลำตัว และอวัยวะเพศ) ค้นหาตามชื่อ หรือคลิกจุดบนโมเดลกายวิภาค 3 มิติ ตำแหน่งที่ดูล่าสุดจะปรากฏเป็นทางลัด

ตัวแสดงภาพมุม

ภาพตัดขวางของเนื้อเยื่อพร้อมแท่งและดิสก์ทั้งสองอันที่วาดอยู่บนภาพ

  • ลากดิสก์อันใดอันหนึ่ง ใช้แถบเลื่อน หรือใช้ปุ่มค่าตั้งล่วงหน้า (-15°, -5°, 0°, +5°, +15°) "Animate Shift" จะเลื่อนมุมไปตามช่วง
  • เมื่อช่องตรง ดิสก์ทั้งสองอันจะแนบราบกับผิวหนัง
  • เมื่อช่องเอียง รูปสามเหลี่ยมจะระบุขอบดิสก์ที่กดลงไปในผิวหนัง และวงกลมโปร่งจะระบุขอบที่ยกขึ้น ช่องจะถูกวาดเป็นเส้นประ
  • ค่าที่แสดงคือความยาวของช่องและยาวกว่าเนื้อเยื่อเท่าไร
  • การ์ดสามใบสรุปผล ได้แก่ ค่าเบี่ยงเบนของมุม การสัมผัสของดิสก์ และการจัดแนวของช่อง การ์ดเหล่านี้อธิบายเฉพาะรูปทรงเรขาคณิต สำหรับปัจจัยเสี่ยงการเคลื่อนตัวและการปฏิเสธของร่างกาย เครื่องมือจะลิงก์ไปยังเครื่องมือ Piercing Migration Risk
  • ดาวน์โหลดแผนภาพเป็นไฟล์ SVG หรือ PNG

ความหนาของเนื้อเยื่อและความยาวของช่อง

ป้อนความหนาของเนื้อเยื่อที่วัดได้ด้วยแถบเลื่อนหรือตัวปรับละเอียด 0.1 มม. หรือเลือกค่าบาง ค่าทั่วไป หรือค่าหนาสำหรับตำแหน่งนั้น ความยาวของช่องคำนวณได้ดังนี้:

ความยาวของช่อง = ความหนาของเนื้อเยื่อ / sin(มุม)

ที่ 90° ช่องจะเท่ากับความหนาของเนื้อเยื่อ การเอียงใด ๆ จะทำให้ช่องยาวขึ้น

เครื่องประดับเริ่มต้นจะยาวกว่าช่องเพื่อเว้นที่ให้อาการบวม และจะถูกตัดให้สั้นลงเมื่ออาการบวมลดลง เครื่องมือนี้ไม่ได้คำนวณความยาวเครื่องประดับ แต่ลิงก์ไปยัง Jewelry Size Visualizer สำหรับเรื่องนั้น

เอกสารอ้างอิงตำแหน่ง

สำหรับแต่ละตำแหน่ง:

  • ข้อมูลจำเพาะพื้นฐาน: มุมเป้าหมาย ความหนาของเนื้อเยื่อทั่วไป ชนิดของเนื้อเยื่อ และระยะเวลาการหายทั่วไป
  • เหตุใดจึงใช้มุมนี้: มุมนี้ต้องเว้นที่ว่างอะไรไว้ และจะเกิดปัญหาอะไรหากมุมไม่เหมาะสม
  • รูปแบบความผิดพลาดของมุมทางคลินิก: ภาพตัดขวางเดียวกันที่วาดให้ถูกต้อง ตื้นเกินไป ชันเกินไป และไม่สมมาตร
  • เครื่องประดับเริ่มต้นทั่วไป: ขนาดเกจ ความยาวทั่วไป และช่วงเวลาการลดขนาดทั่วไป พร้อมลิงก์ไปยัง Jewelry Size Visualizer
  • การจัดตำแหน่ง เทคนิค ข้อผิดพลาดที่พบบ่อย และเมื่อใดควรปฏิเสธการทำ
  • การหายและการดูแลหลังเจาะ: ลิงก์ไปยัง Aftercare Schedule Generator และ Healing Tracker เครื่องมือนี้ไม่ได้กำหนดตารางการหาย

ความสมมาตรของการเจาะคู่

สำหรับคู่ (ติ่งหู รูจมูก คิ้ว snake bites หัวนม ear flats):

  • คู่มือจุดอ้างอิง: แผนภาพเส้นอ้างอิงที่ใช้วัด พร้อมการตรวจสอบทีละขั้นตอน
  • ตัวจำลอง: ตั้งมุมซ้ายและขวาและค่าความต่างของความสูง เพื่อดูว่าคู่นั้นตรงกันหรือไม่

โหมดเปรียบเทียบ

แสดงสองตำแหน่งเคียงข้างกัน ได้แก่ มุม ช่วงความหนาของเนื้อเยื่อ ความลึกของช่อง เครื่องประดับเริ่มต้นทั่วไป ระยะเวลาการหาย ที่ว่าง อันตราย และเกณฑ์การปฏิเสธ สามารถพิมพ์การเปรียบเทียบได้

มาตรฐานของสตูดิโอ

บันทึกขนาดเกจเริ่มต้น รูปแบบเครื่องประดับ และหมายเหตุการทำเครื่องหมายที่สตูดิโอของคุณต้องการสำหรับตำแหน่งหนึ่ง ข้อมูลจะถูกบันทึกเฉพาะในเบราว์เซอร์นี้เท่านั้น และแสดงบนแผ่นที่พิมพ์

หมายเหตุ การพิมพ์ และการส่งออก

  • หมายเหตุทางวิชาชีพ: บันทึกไว้สำหรับเซสชันเบราว์เซอร์ปัจจุบัน แยกตามตำแหน่ง
  • พิมพ์หรือบันทึกเป็น PDF: แผ่นข้อมูลตำแหน่งหนึ่งหน้าสำหรับห้องเจาะ ผ่านหน้าต่างพิมพ์ของเบราว์เซอร์
  • ดาวน์โหลด JSON / คัดลอกสรุป: เอกสารอ้างอิงตำแหน่งและหมายเหตุของคุณ

การตั้งค่า

  • หน่วย: มิลลิเมตรหรือนิ้ว
  • ภาษา: อังกฤษ ฝรั่งเศส เยอรมัน อิตาลี สเปน โปรตุเกส และดัตช์
  • ธีมสว่างและธีมมืด
  • ฝังลงในเว็บ: คัดลอกโค้ด iframe จากปุ่มฝังลงในเว็บ

ความเป็นส่วนตัว

ทุกอย่างทำงานในเบราว์เซอร์ของคุณ ไม่มีข้อมูลที่คุณป้อนถูกส่งไปที่ใด การตั้งค่าจะเก็บในที่จัดเก็บในเครื่อง และหมายเหตุจะเก็บในที่จัดเก็บของเซสชัน
