Mélangeur d'encre pour tatouage

Mélangez, mettez à l'échelle, substituez et enregistrez les couleurs d'encre de tatouage pour pouvoir reproduire un mélange.

Manuel d'utilisation complet de l'outil web Mélangeur d'encre pour tatouage de Poli International, créateur des bijoux de corps BioFlex®.

1. Introduction

Le Mélangeur d'encre pour tatouage offre aux tatoueurs professionnels un poste de travail numérique unifié pour les couleurs. Il garantit des formules de pigments reproductibles pour les tatouages en plusieurs séances, une correspondance précise des couleurs selon la norme CIEDE2000, et une compréhension clinique du dépôt du pigment sur différents phototypes de peau.

2. Les 12 modules du studio

Module 1 : mélangeur d'encre direct

  • Objectif : Calculer des rapports volumétriques précis et le nombre de gouttes pour les mélanges multi-pigments.
  • Mode d'emploi :
  1. Dans l'onglet « Color Mixer », choisissez les encres composantes dans la liste déroulante.
  2. Saisissez la marque et le numéro de lot pour la traçabilité du studio.
  3. Ajustez les parts du rapport (par ex. 3 parts Cramoisi, 1 part Bleu cobalt).
  4. Indiquez le volume total du lot requis en millilitres (ml) ou en godets d'encre (#16 / 2 ml).
  5. Cliquez sur Calculer le mélange pour générer la formule finale, les mesures volumétriques, la répartition en pourcentage et l'échantillon visuel avec Lacoordonnées b*.
  6. Si plusieurs marques d'encre sont sélectionnées, vérifiez l' alerte de différence de marque pour les différences de viscosité et de véhicule.
  7. Enregistrez la formule directement ou imprimez une fiche de formule pour votre poste de travail.

Module 2 : solveur de mélange par cible

  • Objectif : Déterminer la recette exacte des composants nécessaires pour reproduire une couleur cible précise à l'aide des algorithmes Kubelka-Munk et CIEDE2000.
  • Mode d'emploi :
  1. Dans l'onglet « Mix by Target », saisissez un code hexadécimal ou choisissez parmi des préréglages réalistes de couleurs cibles pour tatouage (Cramoisi profond, Ombre de peau, Vert forêt foncé, etc.).
  2. Le solveur calcule la correspondance mathématique la plus proche avec les pigments disponibles dans votre inventaire.
  3. Comparez les couleurs cibles et mélange prévu échantillons avec l'indice de différence de couleur ΔE (Delta E).
  4. Cliquez sur Charger dans le mélangeur pour effectuer des micro-ajustements manuels, ou Enregistrer dans la bibliothèque pour enregistrer le résultat.

Module 3 : inventaire du studio et stock de pigments

  • Objectif : Suivre les flacons de pigment disponibles, les numéros de lot et les dates de péremption.
  • Mode d'emploi :
  1. Ouvrez l'onglet « Inventory » pour consulter le stock de votre boutique.
  2. Filtrez par marque ou catégorie (primaire, neutre, lavis).
  3. Marquez les articles comme « En stock » ou « Épuisé ». Les articles épuisés sont automatiquement exclus ou déclassés par le solveur par cible.

Module 4 : bibliothèque de formules

  • Objectif : Tenir un catalogue de formules personnalisées et accéder à des recettes professionnelles sélectionnées.
  • Mode d'emploi :
  1. Accédez à l'onglet « Saved Formulas » pour rechercher des recettes enregistrées par titre, étiquette ou date.
  2. Cliquez sur Charger la formule pour transférer n'importe quelle recette dans le mélangeur actif.
  3. Cliquez sur Exporter la bibliothèque (JSON) pour télécharger une sauvegarde locale complète, ou Exporter en CSV pour les journaux physiques du poste.
  4. Utilisez Importer la bibliothèque pour restaurer des sauvegardes précédentes sans envoyer de données sur le réseau.

Module 5 : vue de substitution d'encre des formules

  • Objectif : Évaluer rapidement et formuler des remplacements lorsqu'une teinte d'encre du projet est épuisée en cours de séance.
  • Mode d'emploi :
  1. Ouvrez la « Substitution View » dans l'onglet Saved Formulas.
  2. Sélectionnez une recette enregistrée dans votre bibliothèque de formules.
  3. Marquez une encre ingrédient comme épuisée.
  4. Sélectionnez une encre de remplacement dans l'inventaire de votre studio.
  5. Vérifiez les échantillons de couleur Avant et Après côte à côte.
  6. Examinez la différence de couleur CIEDE2000 (ΔE₀₀). Si ΔE > 5,0, tenez compte de l'avertissement bien visible : « This will not match. Mix a test cap first. »
  7. Notez que la couleur à l'écran n'est qu'indicative sur un écran non calibré.
  8. Cliquez sur Charger dans le Mélangeur pour affiner les rapports, ou Enregistrer la Recette Substituée pour enregistrer la formulation ajustée dans votre bibliothèque.

Module 6 : studio de référence et extracteur de palette

  • Objectif : Extraire directement les palettes de couleurs dominantes à partir des photos de référence du client.
  • Mode d'emploi :
  1. Accédez à l'onglet « Reference Studio » et déposez une image de référence sur le canevas.
  2. Cliquez n'importe où sur le canevas de l'image avec la pipette pour échantillonner des coordonnées personnalisées.
  3. Le système extrait une palette équilibrée de 5 couleurs.
  4. Cliquez sur Convertir en formule sur n'importe quel échantillon extrait pour le charger dans le solveur par cible.

Module 7 : formulateur de capsules de dégradé et de valeurs

  • Objectif : Formuler des capsules d'ombrage progressif pour le noir et gris et les transitions de couleur douces.
  • Mode d'emploi :
  1. Dans l'onglet « Gradient Caps », sélectionnez une configuration de 3, 4, 5 ou 6 godets.
  2. Définissez votre pigment de base foncé et votre médium diluant.
  3. Lisez la recette goutte à goutte par godet pour assurer des paliers tonaux réguliers sur votre palette.

Module 8 : formulateur de diluant et de médium

  • Objectif : Préparer en toute sécurité des solutions d'ombrage et des médiums diluants personnalisés.
  • Mode d'emploi :
  1. Ouvrez l'onglet « Diluent Formulator » et choisissez votre application (lavis fin, médium de liner ou solution d'ombrage dense).
  2. Ajustez le volume pour obtenir des rapports précis d'eau distillée, d'hamamélis de qualité cosmétique et de glycérine végétale.

Module 9 : série de mélanges de lavis gris du studio

  • Objectif : Standardiser les dilutions de lavis noir, de la teinte légère (5%) à la nuance profonde (90%), et calculer les séries maîtresses à 3, 4 et 5 godets.
  • Mode d'emploi :
  1. Dans l'onglet « Gray Wash », sélectionnez un système de studio préconfiguré (3-Cap Essential, 4-Cap Smooth Shading ou 5-Cap Micro-Gradient).
  2. Choisissez la taille du contenant (godets n° 9, 12, 16, ou flacons souples de 1 oz, 2 oz, 4 oz).
  3. Utilisez le curseur pour des pourcentages de dilution de lavis continus, en copiant ou en chargeant directement les recettes dans le mélangeur.

Module 10 : éclairage et calibrage du studio

  • Objectif : Garantir une perception exacte des pigments et éviter l'échec métamérique.
  • Mode d'emploi :
  1. Vérifiez les paramètres d'éclairage recommandés pour le studio (éclairage équilibré jour de 5000 K à 6500 K avec IRC > 95).
  2. Vérifiez les conseils de configuration de l'éclairage avant d'évaluer la saturation des couleurs sur des tatouages en cicatrisation.

Module 11 : théorie et principes des couleurs

  • Objectif : Revoir la physique de base du mélange des couleurs, le pouvoir colorant des pigments et la neutralisation complémentaire.
  • Mode d'emploi :
  1. Lisez les guides sur le comportement des pigments pour comprendre pourquoi les pigments très opaques (comme le blanc de titane) doivent être dosés avec parcimonie.
  2. Utilisez le calculateur de neutralisation soustractive pour corriger les sous-tons indésirables du tatouage.

Module 12 : outils du studio et coffre

  • Objectif : Protéger les dossiers clients et les recettes propriétaires du studio par un chiffrement local AES-GCM 256 bits.
  • Mode d'emploi :
  1. Ouvrez l'onglet « Studio Tools & Vault ».
  2. Créez une phrase secrète pour chiffrer toutes les recettes et notes clients enregistrées dans un .vault fichier de sauvegarde hors ligne.
  3. Déchiffrez sur n'importe quel ordinateur du studio sans que les données ne quittent jamais votre navigateur.

3. Vérification et conformité

  • Protection des données : Rien de ce que vous saisissez n'est envoyé. Les formules, l'inventaire et les notes sont stockés uniquement dans votre navigateur, et l'effacement des données du site les supprime.
  • Avis sur les normes de sécurité : Les pigments de tatouage et les formulations de studio doivent respecter les pratiques professionnelles établies et les restrictions chimiques régionales applicables, telles que l'annexe XVII du règlement REACH de l'UE.
  • Outil de correspondance des teintes de peau : Pour une analyse approfondie de la visibilité des pigments selon les phototypes de Fitzpatrick et l'interaction avec la mélanine après cicatrisation, utilisez notre outil complémentaire dédié à https://poliinternational.com/skin-tone-pigment-matcher/.
