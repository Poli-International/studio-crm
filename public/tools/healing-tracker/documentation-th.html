Tattoo & Piercing Healing Tracker

สถาปัตยกรรม ข้อกำหนดตรรกะ โครงสร้างข้อมูล และคู่มือการเชื่อมต่อ

1. ภาพรวมสถาปัตยกรรม

Healing Tracker เป็นเว็บแอปพลิเคชันที่ทำงานฝั่งเบราว์เซอร์ (client-side) และพึ่งพาตัวเองได้ ออกแบบมาเพื่อคำนวณและแสดงผลการคาดการณ์การฟื้นตัวของแผลในแต่ละระยะสำหรับการเจาะร่างกายและรอยสัก โดยไม่ต้องพึ่งพาการเชื่อมต่อเครือข่ายภายนอก ไม่ต้องใช้เซิร์ฟเวอร์ และไม่มีสคริปต์ติดตามใดๆ

  • HTML5: การเขียนมาร์กอัปเชิงความหมาย (semantic) พร้อมตัวควบคุมฟอร์มที่เข้าถึงได้ง่ายและอินเทอร์เฟซแบบแท็บ
  • CSS3: สไตล์ชีตแบบธีมที่ใช้ CSS custom properties และสลับโหมดมืด/สว่างได้ทันที
  • JavaScript: สคริปต์แบบโมดูลาร์ที่คำนวณไทม์ไลน์แบบกำหนดผลได้แน่นอน จัดลำดับความรุนแรงของอาการ และจัดทำรายการตรวจสอบการดูแลหลังทำ
  • Local Storage: บันทึกค่าการตั้งค่าธีมไว้ในเบราว์เซอร์ของผู้ใช้

2. ตรรกะและการคำนวณหลัก

เอนจินการฟื้นตัวคำนวณจำนวนวันที่ผ่านไปโดยใช้ค่าออฟเซ็ตวันมาตรฐานแบบ UTC: 

const procDate = new Date(date);
const today = new Date();
const daysElapsed = Math.max(0, Math.floor((today - procDate) / (1000 * 60 * 60 * 24)));

ตรรกะการจัดลำดับความรุนแรงของอาการ

อาการจะถูกจัดกลุ่มตามเกณฑ์ความรุนแรงสามระดับ:

  • น่ากังวล: จะถูกเรียกใช้เมื่อมีรายงานอาการ เช่น เลือดออกต่อเนื่อง รอยแดงลามเป็นแนว หรือสารคัดหลั่งที่มีกลิ่นเหม็น ระบบจะแนะนำให้ส่งต่อไปยังแพทย์หรือผู้เชี่ยวชาญทันที
  • เฝ้าระวังอย่างใกล้ชิด: จะถูกเรียกใช้เมื่อมีอาการบวมปานกลาง ผิวแดงนานขึ้น หรือรู้สึกอุ่นเฉพาะที่ แนะนำให้สังเกตอาการอย่างใกล้ชิดภายใน 24–48 ชั่วโมง
  • ปกติ: การตอบสนองการฟื้นตัวตามปกติ ได้แก่ น้ำเหลืองใสซึมออกมา (น้ำเหลืองสีขาวขุ่นที่แห้งกลายเป็นสะเก็ด) อาการเจ็บเล็กน้อย และการเกิดสะเก็ดแห้ง

ข้อกำหนดบันทึกการฟื้นตัวและการวิเคราะห์ขั้นสูง

  • การเปรียบเทียบภาพถ่าย: ช่วยให้เปรียบเทียบความคืบหน้าแบบเคียงข้างระหว่างภาพพื้นฐานวันที่ 0 กับบันทึกรายการใดก็ได้ โดยใช้ตัวแบ่งมุมมองแบบแยกที่ลากได้ ถูกนำไปใช้ใน renderPhotoComparison().
  • แนวโน้มอาการและประโยคสรุปชุดข้อมูล: แสดงภาพความรุนแรงของรอยแดง อาการบวม อาการเจ็บ และสารคัดหลั่งตามช่วงเวลาด้วยกราฟเส้น SVG ล้วน และคำนวณประโยคสรุปแนวโน้มการฟื้นตัว ถูกนำไปใช้ใน renderSymptomTrends() และ generateSymptomSentences().
  • การตรวจจับการเปลี่ยนทิศทาง: ระบุการกลับทิศทางที่ต่อเนื่องหลายวันจากแนวโน้มที่ดีขึ้น ถูกนำไปใช้ใน detectDirectionChange() โดยกำหนดเกณฑ์ที่เข้มงวดคือ 3 รายการที่แย่ลงติดต่อกัน (หรือ >= 48 ชั่วโมงของการเพิ่มขึ้นต่อเนื่อง) เพื่อลดการแจ้งเตือนที่คลาดเคลื่อนจากการเสียดสีรายวันชั่วคราว และให้สตูดิโอตรวจสอบได้ทันเวลา
  • ตัวกระตุ้นการเปลี่ยนแปลง: ระบบจะถามปัจจัยทางกายภาพโดยอัตโนมัติ (เช่น ถูกเกี่ยว นอนทับ ใส่เครื่องประดับใหม่ เปลี่ยนผลิตภัณฑ์ ว่ายน้ำ ออกกำลังกาย หรือการเจาะอื่นที่อยู่ใกล้เคียง) ทุกครั้งที่อาการแย่ลงเมื่อเทียบกับรายการก่อนหน้า ถูกนำไปใช้ใน evaluateWhatChangedTrigger(). บันทึกสาเหตุโดยไม่มีการวินิจฉัย
  • การสำรองและกู้คืนข้อมูล: การส่งออกและนำเข้าไฟล์ JSON ไฟล์เดียวที่ทำงานได้ด้วยตัวเอง พร้อมภาพความคืบหน้าแบบ base64 ที่ฝังอยู่ เพื่อย้ายข้อมูลข้ามอุปกรณ์ ถูกนำไปใช้ใน exportBackupData() และ importBackupData().

เอนจินคำนวณอายุการใช้งานของการทำสีซ่อมและการซีดจาง

เครื่องคำนวณอายุการใช้งานกำหนดระยะเวลาที่เหมาะสมสำหรับการทำสีซ่อม โดยใช้ตัวคูณปรับค่าที่ได้จากประสบการณ์จริง:

  • อายุการใช้งานพื้นฐาน: คำนวณจากความหนาแน่นของสไตล์ (เช่น 10–15 ปีสำหรับลายชนเผ่า (tribal) และลายแบล็กเวิร์ก (blackwork) ไปจนถึง 3–5 ปีสำหรับเส้นบาง (fine line) หรือสีน้ำ (watercolor))
  • ตัวคูณตามตำแหน่ง: ปรับตามแรงเสียดทานและอัตราการผลัดเซลล์ผิวชั้นนอก (ปกปิด: 1.1x, สัมผัสเป็นครั้งคราว: 1.0x, สัมผัสบ่อย: 0.8x, แรงเสียดทานสูง: 0.5x)
  • ลำดับอายุการใช้งานของเม็ดสี: คำนึงถึงความทนแสงทางเคมีที่แตกต่างกัน (ดำ > น้ำเงินเข้ม > เขียว/ม่วง > แดง > เหลือง > ส้ม > ชมพู > ขาว)
  • ตัวปรับค่าการดูแลและรังสียูวี: ใช้ตัวปรับค่าที่ได้จากประสบการณ์สำหรับการให้ความชุ่มชื้นประจำวัน และการป้องกันด้วยครีมกันแดด SPF 50+ ที่ครอบคลุมรังสีหลายช่วงคลื่น

3. คำถามที่พบบ่อยและข้อเท็จจริงทางคลินิก

คำอธิบายทางคลินิกที่อ้างอิงหลักฐาน เกี่ยวกับวัสดุ การซึมของน้ำเหลือง และความเข้ากันได้ทางชีวภาพในระยะยาว

ถาม: ไทเทเนียมเป็นวัสดุเดียวที่ปลอดภัยสำหรับเครื่องประดับเจาะครั้งแรกใช่หรือไม่?

ข้อเท็จจริง: ไม่ใช่ ไทเทเนียมระดับการปลูกถ่าย (เช่น ASTM F-136 หรือ ISO 5832-3) เป็นวัสดุที่เฉื่อยมากและได้รับการแนะนำอย่างแพร่หลายสำหรับการเจาะใหม่ แต่ไม่ใช่ตัวเลือกที่ปลอดภัยเพียงอย่างเดียว วัสดุอื่นที่ได้รับการยอมรับและเข้ากันได้ทางชีวภาพซึ่งเหมาะกับการฟื้นตัวในระยะแรก ได้แก่ สแตนเลสศัลยกรรมระดับการปลูกถ่าย (เช่น ASTM F-138) ไนโอเบียมที่เข้ากันได้ทางชีวภาพ (ASTM B392) ทองคำแท้ 14k หรือ 18k ที่ไม่มีนิกเกิล และเครื่องประดับร่างกาย BioFlex® ซึ่งเป็นโคพอลิเมอร์สุ่ม PP-R โดยเรซินผ่านเกณฑ์ USP Class VI เครื่องประดับเจาะครั้งแรกที่ปลอดภัยต้องมีความเข้ากันได้ทางชีวภาพที่พิสูจน์แล้ว ไม่เป็นพิษ และเป็นไปตามขีดจำกัดการปลดปล่อยนิกเกิลที่เข้มงวด ไม่ใช่การพึ่งวัสดุชนิดเดียวโดยเฉพาะ

ถาม: เครื่องประดับร่างกาย BioFlex® ออกแบบมาเพื่อสวมใส่เฉพาะระยะสั้นหรือชั่วคราวใช่หรือไม่?

ข้อเท็จจริง: ไม่ใช่ เครื่องประดับร่างกาย BioFlex® ทำจาก PP-R (โพลิโพรพิลีนโคโพลิเมอร์สุ่ม) เรซินผ่านเกณฑ์ USP Class VI และ Ph. Eur. 3.2.2 และวัสดุได้รับการรับรองว่าผ่านการทดสอบทางชีวภาพตาม ISO 10993 เหมาะสำหรับการสวมใส่ระยะยาวและการเจาะครั้งแรก สามารถฆ่าเชื้อด้วยไอน้ำในออโตเคลฟ (autoclave) ได้ และความยืดหยุ่นช่วยลดแรงกดต่อเนื้อเยื่อ หมายเหตุเกี่ยวกับความแตกต่างของวัสดุ: BioFlex® ไม่ใช่ PTFE (พอลิเตตระฟลูออโรเอทิลีน) PTFE เป็นฟลูออโรพอลิเมอร์ที่ผ่านการกลึงจากแท่ง มีคุณสมบัติเชิงกลและการขึ้นเกลียวที่แตกต่างกัน ส่วน BioFlex® เป็นโคพอลิเมอร์ PP-R ที่ผลิตเป็นชิ้นเดียว ไม่มีรอยต่อหรือส่วนที่ใช้กาว ทั้งสองวัสดุไม่ได้ถูกจำกัดให้สวมใส่ได้เฉพาะระยะสั้นเมื่อใช้อย่างเหมาะสม

ถาม: แผลเจาะมีของเหลวใสหรือสีขาวขุ่นที่แห้งเป็นสะเก็ด หมายความว่าติดเชื้อหรือไม่?

ข้อเท็จจริง: ไม่ใช่ ของเหลวใส สีขาวอ่อน หรือสีฟางข้าวที่แห้งเป็นสะเก็ด ("crusties") คือน้ำเหลือง (lymph) ผสมกับเซลล์ที่ตายแล้ว การผลิตน้ำเหลืองเป็นส่วนปกติและมีประโยชน์ของกระบวนการสมานแผลของร่างกายในทุกระยะของการเจาะ ไม่ใช่หนอง และไม่ใช่สัญญาณของการติดเชื้อ สัญญาณของการติดเชื้อจริงมีลักษณะแตกต่างชัดเจน ได้แก่ หนองข้นทึบสีเหลืองหรือเขียวเข้ม ความร้อนที่แผ่กระจาย ผิวแดงเข้มที่ลามออกไป อาการปวดตุบๆ หรือมีไข้ทั่วร่างกาย
